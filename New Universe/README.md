## Прогонка и публикация версий

Правило: **каждое изменение** проходит прогонку и публикуется как новая версия.

```powershell
# Прогонка + коммит + тег vX.Y.Z + push (версия поднимается автоматически)
.\publish.ps1 -Message "краткое описание изменений"

# Конкретная версия вручную (например, минор):
.\publish.ps1 -Message "новая фича" -Version 1.1.0
```

Скрипт `publish.ps1`:
1. выполняет прогонку (проверка целостности проекта, см. `run-checks.ps1`);
2. добавляет все изменения `New Universe/` в коммит;
3. создаёт тег `vX.Y.Z` и записывает версию в файл `VERSION`;
4. публикует ветку `master` и тег в `origin` (GitHub).
