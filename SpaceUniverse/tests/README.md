# Тесты

Автоматический тестовый фреймворк (GdUnit4/GUT) пока не подключён.

## Политика
- При каждой компиляции/сборке проекта следует прогонять тесты.
- В среде без установленного Godot CLI выполняются статические проверки (ссылки `res://`, базовая целостность скриптов/сцен).

## Запуск
1. Установите Godot 4.7.2 (console).
2. Укажите путь: `set GODOT_EXE=C:\path\to\Godot_v4.7.2-stable_win64_console.exe`
3. Запустите из папки `SpaceUniverse`: `run_tests.cmd`

`run_tests.cmd` выполняет headless-проверку проекта (`--check-only`). После подключения тестового фреймворка добавьте команду запуска тестов в этот скрипт и размещайте тесты в `tests/`.
