# Voxel Frontier

Мини-песочница в духе **Dual Universe**: воксельная планета, строительство, сбор кристаллов и полёт на корабле. Работает офлайн, без установки и сборки.

## Запуск

**Двойной клик по `index.html`** — игра откроется в браузере (Chrome, Edge или Firefox). Интернет не нужен.

Если браузер по каким-то причинам не захватывает курсор при открытии через `file://`, можно запустить локальный сервер:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1
```

и открыть <http://localhost:8137/>. Остановить сервер — `Ctrl+C` в его окне.

## Управление

| Клавиши | Действие |
|---|---|
| `W` `A` `S` `D` | движение |
| Мышь | обзор |
| `Пробел` | прыжок / реактивный ранец |
| `Shift` | бег (на земле) / спуск (в полёте) |
| `ЛКМ` | поставить блок |
| `ПКМ` | убрать блок |
| `1`–`6`, колесо мыши | выбор материала в хотбаре |
| `I` / `E` | открыть / закрыть инвентарь |
| `F` | сесть в корабль / выйти |
| `Esc` | пауза / закрыть инвентарь |

**Корабль:** подойдите к шаттлу на стартовой плите и нажмите `F`. `W`/`S` — тяга вперёд/назад, `A`/`D` — вбок, `Пробел`/`Shift` — вверх/вниз, мышь — направление полёта. Повторный `F` — выйти. Шаттл собран из вокселей 0,5 м, стоит на четырёх стойках шасси и светит круглыми соплами.

## Инвентарь и материалы

Нажмите `I` или `E` — откроется панель со всеми материалами и их количеством. Клик по слоту выбирает материал и закрывает панель; выбранный материал можно ставить `ЛКМ`.

- Стартовый запас: трава, земля, камень и металл — по 128; золото и стекло — по 64; кристаллы — 32.
- Добыча пополняет инвентарь: снятый блок возвращается в запас, собранный кристалл добавляет +1 кристалл.
- Постройка расходует материал; если запас закончился, появится подсказка.
- В хотбаре шесть основных материалов, но в инвентаре доступны все 13 типов, включая **дерево** и **листву** — их можно добыть из деревьев.
- Плита, корпус, двигатель и акцент — корабельные материалы для декоративных построек.

## Что делать

- Собирайте светящиеся **кристаллы** — подойдите к ним вплотную. Они разбросаны по всей поверхности планеты.
- Стройте базу из травы, камня, металла, золота, стекла и кристаллов. Прицел подсвечивает блок, с которым взаимодействуете.
- Исследуйте планету, поднимайтесь на холмы, любуйтесь дальними берегами и летайте на шаттле.

## Сохранение

Мир сохраняется автоматически каждые 4 секунды и при паузе (в `localStorage`, ключ `voxel-frontier-v1`). Позиция игрока, корабль, кристаллы, инвентарь и все изменения блоков восстанавливаются при следующем запуске. Предыдущая версия сохранения дублируется в `voxel-frontier-v1-backup` — на случай случайной перезаписи.

Сбросить мир — ссылка **«Сбросить мир»** на стартовом экране.

## Технические заметки

- Чистый JS + Three.js r128 (UMD), без сборщика и ES-модулей — поэтому игра открывается прямо с диска.
- Мир — 64×64 воксельная планета с холмами и ровной стартовой площадкой; рендер блоков через `InstancedMesh`.
- Графика: процедурные текстуры блоков (атлас «верх/бок/низ»), анимированная вода с bump-картой, мягкие спрайтовые облака, пыль, частицы, свечение кристаллов и сопел, тёплый горизонт и ореол солнца.
- Растительность: 14 воксельных деревьев, трава и цветы из crossed-quads (без коллизий), дальние заземлённые берега на горизонте.
- Анимации: блоки появляются с упругим масштабом, кристаллы и двигатели пульсируют, акцентные элементы дышат.
- Цвета материалов переводятся в линейное пространство (`convertSRGBToLinear`) — это важно для корректной насыщенности при `sRGBEncoding`.
- Отладочный режим: откройте `index.html?debug` — появится объект `window.__vf` (телепорт, состояние, установка блоков, захват кадра). На обычную игру не влияет. `?debug&fresh` запускает чистый мир без загрузки сохранения и **не перезаписывает** сохранение игрока; `?nosave` отключает запись для любого запуска.
